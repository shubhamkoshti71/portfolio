I'm a data professional who wears three hats: I build the pipelines that move data (Data Engineer), shape it into metrics and dashboards people trust (Analytics Engineer), and write the code and automation that keeps it all running (Developer). These days, as a Data Analytics Engineer at Quantegy Analytics, I own the pipelines, work directly with the people who rely on the data, and make the call on how to build it.
